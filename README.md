📝 Todo App

    A clean, minimalistic to-do list application built with vanilla JavaScript to help you stay organized and productive.

🚀 Live Demo

View Live Demo (https://darksyntax1312.github.io/todo-app/) 
✨ Features

    ✅ Add new tasks with a single click

    ✏️ Edit existing tasks inline

    🗑️ Delete tasks you've completed

    ✔️ Mark tasks as complete/incomplete

    💾 Persistent storage with localStorage (tasks survive page refresh)

    📱 Fully responsive design (works on mobile & desktop)

    🎯 Clean, intuitive user interface

    🔄 Real-time task counter

🛠️ Tech Stack

    HTML5 - Semantic markup

    CSS3 - Custom styling with Flexbox/Grid

    JavaScript (ES6+) - Vanilla JS, DOM manipulation, LocalStorage API

🎨 Design Highlights

    Minimalist and distraction-free interface

    Smooth animations and transitions

    Color-coded status indicators

    Accessible and keyboard-friendly
